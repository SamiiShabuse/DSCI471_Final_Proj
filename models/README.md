# Models Directory

Generated model artifacts live here. Most are excluded from new git additions
by `.gitignore`; some older ablation/cache artifacts may exist in local copies
or in the course submission folder.

## Layout

```text
models/
|-- v4_image_encoder.weights.h5      # Final model weights; generated locally
|-- test_image_embeddings.npy        # Cached test gallery embeddings; generated by evaluate.py
|-- embeddings/
|   |-- train_text.npy               # Cached MiniLM train captions
|   `-- val_text.npy                 # Cached MiniLM validation captions
`-- experiments/                     # Richardson ablation weights and plots; optional
```

## Regenerate the Final Model

From the project root with `venv` activated and `data/processed/` present:

```powershell
# 1. Train final v4 image encoder (~40 min on CPU; faster with GPU)
python src/train.py

# 2. Run evaluation (builds test_image_embeddings.npy if missing)
python src/evaluate.py
```

The first dual-encoder run requires internet/Wi-Fi for Hugging Face MiniLM
unless `sentence-transformers/all-MiniLM-L6-v2` is already cached locally.

Smoke test on a small subset:

```powershell
python src/train.py --sample 800 --baseline-epochs 1 --finetune-epochs 1
python src/evaluate.py --sample 500
```

## Ablation Artifacts

`models/experiments/` is only needed to reproduce Richardson's v1-to-v5
notebook story. Re-run notebooks in `notebooks/richardson_experiment/`
(`02` through `08`) or skip this folder if you only need the final `src/`
pipeline.

Metrics from those runs are saved as CSVs in `docs/reports/ablations/`.

## Course Submission

If the grader cannot retrain:

1. Preferred: submit this repo plus `models/v4_image_encoder.weights.h5` and
   `models/test_image_embeddings.npy`, or submit the full local `models/`
   folder with the project zip.
2. Alternative: note in the report that dual-encoder evaluation requires
   running `train.py` once; include `docs/reports/evaluation_results.csv` as
   the graded output evidence.
