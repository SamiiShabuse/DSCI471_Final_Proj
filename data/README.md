# Data

Raw Kaggle files and generated splits live here. They are not stored in git
except for this README.

## Layout

```text
data/
|-- raw/fashion-dataset/     # Kaggle download: images/, styles.csv, styles/
`-- processed/               # Generated by src/prepare_data.py
    |-- pairs.csv            # All products
    |-- train.csv            # Training split
    |-- val.csv              # Validation split
    |-- test.csv             # Held-out test split
    |-- products.csv         # TF-IDF index
    `-- *_aug.csv            # Optional ablation splits from Richardson notebooks
```

## Required Setup

Run from the project root in every fresh clone or clean environment:

```powershell
python src/download_kaggle_data.py   # or place Kaggle files manually
python src/prepare_data.py           # builds data/processed/
python src/prepare_data.py --check   # verifies splits without rebuilding
```

`prepare_data.py` must run before `train.py` or `evaluate.py`. It creates
splits with `product_text` (caption + JSON description) used by the TF-IDF
baseline and evaluation pipeline.

## Validate Existing Splits

If you see errors like `missing columns ['product_text']`, your
`data/processed/` files are stale, often from an older experiment copy:

```powershell
python src/prepare_data.py --check   # diagnose
python src/prepare_data.py           # fix
```

## Augmented Splits

Files such as `train_aug.csv` come from
`notebooks/richardson_experiment/05_caption_augmentation.ipynb`. They use a
different schema (`style` column for query-type rotation) and are only needed
for Richardson's v2-v5 ablation notebooks, not for the main `src/train.py` or
`src/evaluate.py` pipeline.

Do not replace `train.csv`, `val.csv`, or `test.csv` with the augmented
versions.
